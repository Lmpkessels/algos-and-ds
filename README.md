Is a repository that covers the most important algorithms and data-structure in CS to solve complex problems.

## What this repository is for

This repository is to deepen my problem solving ability, understanding of algorithms, and data-structures, so I can create efficient code.

## Algorithms that'll get covered

- Binary search
- Quick sort
- Merge sort
- Heap sort
- BFS (Breadth first search)
- DFS (Depth first search)
- Topological sort
- Amortized analysis (dynamic array growth)
- Hash collision analysis / load factor behavior

## Data-structures that'll get covered

- Dynamic array (Vec-like)
- Singly linked list
- Doubly linked list
- Hash table (open addressing and/or chaining)
- Binary heap (priority queue)
- Binary search tree
- Graph (adjacency list)
- Merkle tree

## Setup

```bash
git clone https://github.com/Lmpkessels/algos-and-ds.git
cd algos-and-ds

# For C
cd c
gcc tests/test_name.c directory_name/name.c -o build/test_name
build/./name

# For Rust
cd rust
cargo test
```

Navigate through folders by topic.
