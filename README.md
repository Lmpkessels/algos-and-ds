## Setup

```bash
git clone https://github.com/Lmpkessels/algos-and-ds.git
cd algos-and-ds

# For C
cd c
gcc tests/test_name.c directory_name/name.c -o build/test_name
./build/name

# For Rust
cd rust
cargo test
```

Navigate through folders by topic.
